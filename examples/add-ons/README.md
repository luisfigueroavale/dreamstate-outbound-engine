# Add-ons

Three optional graphs. Each one is disabled. None of them send in v1.

| Add-on | What it covers |
| --- | --- |
| [inbound-form-to-crm](inbound-form-to-crm/README.md) | A form row, then a CRM push only after a yes |
| [post-engagers-to-worksheet](post-engagers-to-worksheet/README.md) | Engagers of a post, into the warm worksheet |
| [comment-keyword-to-link](comment-keyword-to-link/README.md) | A keyword rule that routes a commenter toward the warm worksheet |

The keyword add-on overlaps `send-lead-magnet` in [dreamstate-linkedin-funnel](https://github.com/luisfigueroavale/dreamstate-linkedin-funnel). That skill owns the content. This note owns only the route into the engine.
