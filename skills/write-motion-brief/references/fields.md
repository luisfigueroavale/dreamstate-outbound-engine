# Brief fields

The local file needs outcome, ideal customer, offer, campaign code, audience cap, credit ceiling, and worksheet. Fit, signals, and the test are pointers to the other motion files, not copies of Company Context.

Write only in motion.local/brief.md. Use the owner's words for the cap and the ceiling. A campaign code is a short label the owner chooses.

Read the filled lines back to the owner before you save. Ask them to correct a number you were unsure of.

Stop if you would have to guess a ceiling. Do not copy a sample number from the fleet example into a real brief.
