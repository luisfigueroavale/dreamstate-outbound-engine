# Demo

The command is npm run demo. It reads examples/first-batch/batch.json and writes output/demo/report.md plus the committed twin at examples/first-batch/report.md. No catalog inputs.

This is a local Node script. It does not call Dreamstate. Credits on the report must be 0 and sent must be 0.

Show the owner the funnel counts and one hold line per company. Point at the rank order of the selected accounts.

Stop if the report shows a send or a credit above 0. Do not treat the demo as permission to run a live source.
