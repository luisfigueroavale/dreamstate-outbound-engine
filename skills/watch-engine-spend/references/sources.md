# Run list

runs_list is a free MCP read of recent runs. It is not a catalog id. Fetch it before you use it. Look for a source run whose time is outside the approved window in the brief.

There is no dry_run. Say that it was a read. Do not pass a filter you have not fetched. Match run ids to the history list when both name the same capability.

Show the owner the run id, the time, and the capability. Say whether it sits inside the window.

Stop after the flag. Do not disable, enable, or schedule anything from this skill. A schedule is a standing action and needs its own yes.
