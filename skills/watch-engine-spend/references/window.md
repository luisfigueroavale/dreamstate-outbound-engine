# Spend window

Call whoami first. workspace.usage.spend_breakdown needs from, an ISO timestamp. to is optional. group_by defaults to capability. limit defaults to 50. The read is free and has no dry_run. Say that it was a read.

Fetch tools_get, then tools_run live. Compare the total with the credit ceiling in the brief. Run npm run spend-check on a saved copy of the rows if you want the local flags.

Show the owner the window, the total, and the ceiling. Name the largest capability ids.

Stop if from is missing. Do not guess a start date. Do not hide a total that sits above the ceiling.
