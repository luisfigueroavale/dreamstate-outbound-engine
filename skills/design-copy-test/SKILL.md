# Design copy test

Follow `docs/skill-frame.md`.

## Use when

- A first touch exists and the owner wants a test.
- More than one sentence would change at once.

## Steps

1. Write one changed variable in `motion.local/test.json` (`references/one-variable.md`).
2. Run the local `assign-variant` function (`references/assign.md`).

## Stop

- dry_run first, quote, wait for the owner's yes on that item
- Do not send, enroll, launch, post, schedule, or delete.
