# Fit column

tables.columns.catalog takes an optional family. Use classification. The fit card is column.ai_fit_score with template icp_fit_score, at 0.04 credits a row. prompt is required and model_id is optional. tables.columns.add needs table_id and name, plus binding_spec.definition_id.

Fetch tools_get for the catalog and for tables.columns.add. The catalog read is live and free. The add starts as dry_run. Wait for a yes on that quoted item before any live call.

Show the owner the definition id the catalog returned, the 0.04 credit price, and the dry_run preview. Wait for a yes before the live add.

Stop if the catalog does not return column.ai_fit_score. Do not invent a card key such as a shortened fit name. Do not add the column to a worksheet the owner did not name.
