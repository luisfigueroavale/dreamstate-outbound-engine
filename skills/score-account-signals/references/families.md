# Signal families

Call whoami first. Read motion.local/signals.json for points, half life, cutoff, and which families are strong. tables.findable_catalog.list is a free read with no required input. Copy definition ids from that response.

Fetch tools_get, then tools_run live for the catalog. Say that it was a read. Do not paste a remembered id if the catalog does not return it.

Show the owner the families you will price and the point value of each. Mark which ones are strong enough to reach tier B or A alone.

Stop if the local signal file is still the blank template. Stop if a family you need is missing from the catalog. Do not score with a family the file does not name.
