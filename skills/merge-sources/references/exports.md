# Exports

Call whoami first. The local merge-sources function takes records with domain, source_id, name, and signals. It strips scheme, www, path, port, and case. tables.rows.query needs table_id if you also read a worksheet.

Run the local function on the export file. If you query Dreamstate, fetch tools_get for tables.rows.query, then tools_run live. Say that the query was a read.

Show the owner the account count, the rejected rows, and any domain that kept more than one signal.

Stop if a domain fails the shape check and you are tempted to repair it by hand into a real company. Put that row in the rejected list with the reason.
