# Uncertain identity

A domain match is not enough when the names differ or the signals describe two industries. The function keeps one account per domain only when you pass it rows you already trust as the same company.

There is no extra catalog call. Compare name, source_id, and signal detail before you pass the rows in. Hold the pair instead of merging when you cannot prove they are one company.

Show the owner the two names, the domain, and the sentence you would need to be sure. Ask them to pick one, both, or neither.

Stop and leave both rows out of the merged file when the owner does not answer. Do not pick the richer row because it has more signals.
