# CRM search

Call whoami first. crm.records.search is a free read. Required fields are none in the current contract. Pass the domain or the name the worksheet already holds. Unknown is not the same as new.

Fetch tools_get, then tools_run live. Say that it was a read. Do not follow the search with a write in the same turn.

Show the owner the match count and whether the top match is exact on domain.

Stop if the search errors. Do not class the row as new because the call failed. Leave it as a failed lookup.
