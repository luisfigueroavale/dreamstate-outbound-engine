# Glossary

| Word | Meaning |
| --- | --- |
| Account | One company, one normalised domain. |
| Tier | A, B, or C from signal points after fit has passed. |
| Gate | A yes or no that can exclude a row even when the score is high. |
| Ready | Both gates passed, email valid and fresh, reviewed, suppression clear, capacity left, draft sequence id set, test ids set, no token, body inside the word limit. |
| Hold | A named reason the row does not move. |
| Quote | The dry run price. It is not a yes. |
| Ceiling | The credit number in the brief. Spend above it is an overrun. |
| Unclaimed | Credits in the spend read that no step in the batch claimed. |
| Coverage path | Every fit company, slowly, under the cap. |
| Signal path | A fresh strong signal jumps the queue. Fit still wins. |
