# Dreamstate skills

This repo does not copy the Dreamstate skills. They already live in the workspace and in [dreamstate-plugins](https://github.com/luisfigueroavale/dreamstate-plugins). Load the bare id with `skills_get` when you do that pack's work. `skills_list` confirmed these ids on 2026-11-21.

| Job | Dreamstate skill | This repo |
| --- | --- | --- |
| Build the list | `list-building` | `build-account-list` decides caps and order |
| Warm people from posts | `linkedin-warm-signals` | The add-on note only |
| Signals | `dreamstate-signals` | `score-account-signals` sets points and tiers |
| Fill a missing field | `enrichment` | `find-verified-email` holds catch-all |
| Sequences | `outreach` | `hand-off-to-sequence` stops before enroll |
| Mailbox health | `deliverability` | Read only, through the sequences seat |
| Why a row is empty | `diagnostics` | Spend and hold reasons |
| Replies | `inbox-replies` | Not in this repo |
| CRM records | `crm` | `check-crm-first` |
| Company context | `knowledge` | The brief points at the pages |
| Workflows | `workflows` | Disabled graphs only |
| Tidy a worksheet | `worksheet-tidy` | After a merge |
| Plays | `plays` | Not a substitute for this engine |
| Custom HTTP | `custom-http` | DNS as a signal is unconfirmed and not built |
| Posts and articles | `linkedin-posts`, `x-posts`, `writing` | The fleet recap is a draft to hand over |
| Graphics | `visual-design` | The fleet file is a brief, not a render |
| Social scheduling | `social` | Not in this repo |

A skill teaches judgement. It does not grant a send.
