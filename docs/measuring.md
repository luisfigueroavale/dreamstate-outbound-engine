# Measuring

Every rate shows its numerator and its denominator. Unknown is not zero. A missing report is not zero.

Count a reply or a meeting only when the message was delivered, and only inside the same test, audience, variant, and prompt version. Duplicate message ids collapse to one row. If the same id disagrees with itself, the read fails.

The review floor is 100 delivered messages per variant. Under that floor the verdict is too little data.

The interval is a Wilson 95 percent interval on the positive reply rate. Ahead or behind only when the two intervals do not overlap. Otherwise the verdict is no clear difference. This is a reading, not a proof.

One changed variable per round. Keep the old settings in Dreamstate Knowledge with the date.

After 30 days, read meetings per 100 accounts by tier. Change weights only after a learning note and a yes.

Spend is credits per tier, per verified email, and per ready buyer, from `workspace.usage.spend_breakdown`.
