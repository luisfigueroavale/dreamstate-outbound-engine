# Start here

This folder decides which companies deserve a first message, who to ask, and what the last round taught. It runs on Dreamstate. The demo runs on your machine and spends nothing.

1. Sign in with `npx @trydreamstate/cli install`. Use the browser. Do not paste a key.
2. Run `npm run demo` and open `examples/first-batch/report.md`.
3. Copy `motion/` to `motion.local/` and fill the brief.
4. Run `npm run plan-install`. Read it. Nothing has run.

The longer path is [../README.md](../README.md). The rules for every skill are [skill-frame.md](skill-frame.md).
